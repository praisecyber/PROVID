# PROVID

A browser-based workspace for creating characters, turning a screenplay into shots, refining clips, and exporting a movie.

## Run locally

From the repository root, run `python3 -m http.server 8000 --directory dist` and open `http://localhost:8000`.

Open **Gemini settings** and enter your own API key to use generation. Projects are saved in your browser. The ManyMotions brief builder prepares a brief you can copy into ManyMotions.
